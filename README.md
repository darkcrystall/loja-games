# Loja de Games

Sistema desktop para gerenciamento de uma **loja de games** desenvolvida em **Java Swing** com persistência em **MySQL via JDBC**, seguindo o padrão **MVC + DAO**

O sistema permite cadastro, edição, exclusão, listagem de jogos e **upload e preview de imagens** dos produtos.

---

# Funcionalidades do projeto
- Cadastro de jogos
- Edição de jogos
- Exclusão de jogos
- Listagem em JTable
- Upload de imagem do produto
- Visualização de imagem
- Armazenamento local de imagem
- Integração com MySQL

---
